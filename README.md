# 筑城之间 · 第一阶段

纯浏览器运行的 Three.js 微缩建筑工地。五名工人按固定图纸分工建造两层办公楼，包含有限库存、推车运输、搅拌、实际吊装、双人安装、休息与自动收工。

## 本地开发

需要 Node.js 22.13+ 和 package.json 指定的 pnpm 版本。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

按命令输出的本地地址打开。构建使用 `pnpm build`，类型检查使用 `pnpm exec tsc --noEmit`。本项目复用 Sites 的 React/Vinext 页面容器；三维场景和模拟引擎是独立 TypeScript 模块，不依赖业务后端，未来可以移入 Vue 项目。

## 使用

打开即自动开工。拖动旋转，滚轮缩放，右键平移；控制栏提供暂停/继续、1×/2×/4×、恢复视角和确认后重置。工地时间是模拟时间，1× 每真实秒约推进 1.6 模拟秒，分工版本典型一轮约 12 分钟，4× 约 3 分钟；运输、设备作业、搭档等待和随机休息会影响时长。

刷新重新开始；切换到隐藏标签页暂停，不补算离线时间；完工后保留房屋。没有 AI、API 密钥、存档、登录、交易、多栋建设或后台进程。启动需要支持 WebGL 2 的浏览器与图形环境；禁用 WebGL 时显示明确提示。

## 调整位置

- `lib/construction/simulation.ts`：固定建筑部件、阶段、任务工期、工人状态机、路线、休息与调度。
- `lib/construction/scene.ts`：模型、材质、灯光、相机、围挡、装饰与动画。
- `app/page.tsx` / `app/globals.css`：观察界面与样式。
- `lib/construction/webmcp.ts`：浏览器支持时可读取状态或设置播放速度与暂停。

## 分工与材料规则

- 01 材料员：推车从仓储区取料，卸到地面施工点或吊装区。只在实际取料完成后扣减库存。
- 02 设备员：基础阶段操作移动搅拌机，结构和上层施工操作吊车控制台。吊臂、滑车、吊钩和所运材料联动；吊装完成后工人才能使用该批材料。
- 03、04 建筑工：浇筑、砌墙与结构装配；梁、楼板、屋架和屋面要求两人到场，任一人未到场或休息都停止该项施工。
- 05 安装工：门窗、雨棚、屋脊与收尾；没有安装任务时可协助基础和单人砌筑。

六类材料以“组”（一份施工料包）计量：混凝土料、钢构件、砌块、木构件、板材、门窗配件。按图纸计算用量，初始额外备约 10% 的材料。没有自动补货或无限资源。可通过开发时调整 stock 模拟缺料；缺料会停止配送和相关施工，不会产生负库存。

材料严格遵守：初始总量 = 仓库库存 + 运输中 + 工地待用 + 已计入建筑。库存模型每一组对应一个可见料包。推车、吊钩、落地待用材料共用任务的材料状态，不重复生成库存。施工期间材料按工程量消耗，最终余额保留。

每个任务有稳定 ID、工程量、负责人、参与者列表和可达站点；配送/设备操作独立于施工负责人。阶段顺序推进，横梁等待立柱，窗户等待对应墙体，屋面等待全部屋架。工期由实际工作量推进。休息保留施工任务，设备员在完成当前混合/吊装周期后再休息。

临时脚手架和外部阶梯作为已布置的工地设施从开工存在，以保证上层站位可达；最终所有工人离开高处后移除。建筑是卡通演示，未进行现实结构认证；导航为简化外环与楼梯路点，带人物路线错位，不是刚体/人群物理系统。

## 验证

```sh
node --experimental-strip-types scripts/check-simulation.mjs
```

该检查覆盖阶段顺序、材料守恒、有限库存、缺料停工、未配送不施工、搅拌依赖、双人配合、暂停不推进、休息恢复、五个工种均有贡献、完成状态及无人悬留高处。完整图纸为 79 项施工任务，当前流程需要 57 次实际吊装。浏览器测试环境的 WebGL 被禁用，因此不能以该环境确认三维画面、帧率和人物通行的视觉质量；需在启用 WebGL 的正常桌面浏览器中检查。
