# 筑城之间 · 第一阶段

纯浏览器运行的 Three.js 微缩建筑工地。五名工人按固定图纸分工建造两层办公楼，包含有限库存、双车运输、实际吊装、按作业面分工与自动收工。

## 本地开发

需要 Node.js 22.13+ 和 package.json 指定的 pnpm 版本。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

按命令输出的本地地址打开。构建使用 `pnpm build`，类型检查使用 `pnpm exec tsc --noEmit`。本项目复用 Sites 的 React/Vinext 页面容器；三维场景和模拟引擎是独立 TypeScript 模块，不依赖业务后端，未来可以移入 Vue 项目。

## 使用

打开即自动开工。拖动旋转，滚轮缩放，右键平移；控制栏提供暂停/继续、1×/2×/4×、恢复视角和确认后重置。工地时间是模拟时间，1× 每真实秒约推进 1.6 模拟秒，按固定 1/30 秒步长回放，当前流程约在工地时间 24:36 完工（优化前为 31:31）。播放倍率只改变观看速度；实际墙钟耗时还取决于浏览器帧率。

刷新重新开始；切换到隐藏标签页暂停，不补算离线时间；完工后保留房屋。没有 AI、API 密钥、存档、登录、交易、多栋建设或后台进程。启动需要支持 WebGL 2 的浏览器与图形环境；禁用 WebGL 时显示明确提示。

## 调整位置

- `lib/construction/simulation.ts`：固定建筑部件、阶段、任务工期、工人状态机、路线、工序依赖与调度。
- `lib/construction/scene.ts`：模型、材质、灯光、相机、围挡、装饰与动画。
- `app/page.tsx` / `app/globals.css`：观察界面与样式。
- `lib/construction/webmcp.ts`：浏览器支持时可读取状态或设置播放速度与暂停。

## 分工与材料规则

- 01、02 运输工：各自沿固定服务道路取料和配送；先认领真实订单，实际装车后扣库存，卸货完成后才允许使用。吊车独立执行上层材料吊装，司机不离开车辆操作吊车。
- 03、04 建筑工：主要负责前侧及左右作业面；05 建筑工主要负责后侧。基础分区均衡分配，施工中负责人不变。
- 每项任务由一名建筑工取料并安装，保持原有工作量和速度。楼上优先在附近的侧边空位待命，后侧保留独立备用位置。
- 取料前检查完整往返作业路线。互不冲突的路线可并行；共用狭窄通道时依次通行，楼梯保留单人占用约束。

六类材料以“组”（一份施工料包）计量：混凝土料、钢构件、砌块、木构件、板材、门窗配件。按图纸计算用量，初始额外备约 10% 的材料。没有自动补货或无限资源。可通过开发时调整 stock 模拟缺料；缺料会停止配送和相关施工，不会产生负库存。

材料严格遵守：初始总量 = 仓库库存 + 运输中 + 工地待用 + 已计入建筑。库存模型每一组对应一个可见料包。推车、吊钩、落地待用材料共用任务的材料状态，不重复生成库存。施工期间材料按工程量消耗，最终余额保留。

每个任务有稳定 ID、工程量、负责人、参与者列表和可达站点。调度按实际前置工序推进：梁等待其承重柱，门窗等待对应墙体，楼板等待首层框架及永久楼梯，二层柱等待楼板，屋架等待二层框架，屋面等待屋架，整理场地等待全部任务。独立的门窗安装不再阻挡后续结构施工。

运输优先补给没有待用料的工人，每人最多预备两批、共用一个卸料槽位。只有前置工序已完成或其材料已取走开始现场作业，才安排后续备料；真正配送和施工仍须等待前置任务完成。这样可提前取货，又不会让不具备开工条件的材料堵住卸料平台。

临时脚手架和外部阶梯作为已布置的工地设施从开工存在，以保证上层站位可达；最终所有工人离开高处后移除。建筑是卡通演示，未进行现实结构认证；导航使用可达地面、脚手架及楼梯路径，并检查工人、车辆、已建部件与物料的碰撞。

## 验证

```sh
node --experimental-strip-types scripts/check-simulation.mjs
node --experimental-strip-types scripts/check-collisions.mjs
pnpm exec tsc --noEmit
```

完整回放保留 79 项任务、510 秒累计安装工作量、120 组材料及 45 次实际吊装；运输速度仍为 5，步行速度仍为 1.8（场景单位/模拟秒），安装、装卸与吊装时长保持不变。

同样的 1/30 秒步长下，优化前后完工时间为 1890.9 秒 → 1476.2 秒，减少 414.7 秒（21.9%）。工期回归上限收紧到 1550 秒。检查覆盖真实配送、库存守恒、结构依赖、速度上限、暂停、缺料停工、全程碰撞、楼梯及平台支撑、自动收工。逻辑回放不能替代实际浏览器中的画面与帧率检查。
